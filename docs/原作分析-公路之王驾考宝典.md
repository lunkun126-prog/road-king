## 二、画面与操作（截图还原）

- 竖屏第一人称，低多边形城市快速路：单向 3~4 车道、护栏、两侧楼房（夜间亮窗），可昼夜。
- 下方仪表区：左边**可拖动的方向盘**，中间车速 km/h，右边**刹车 / 油门**两个踏板按钮。
- 右侧两个圆按钮：**远光灯**、**喇叭**。
- 顶部导航条：`↑直行` + 红黄绿三个灯点 + 距下个路口米数 + 剩余秒数。
- 撞车后画面泛红、车速归零 → 结束。

## 三、规则与玩法

1. **核心循环**：沿直路一直开，躲避不停变道「别车」的 NPC，路口有红绿灯；撞了就「追尾」结束。
2. **完好度（血量）**：有血条，但评论说「轻轻碰一下完好度直接变 0」。
3. **红绿灯**：红灯约 15 s，绿→黄 4 s；等灯时后车会追尾你。
4. **模式**：经典模式、剧情模式（关卡，如「180 度掉头后打双闪」）、狂暴模式（高速跑距离，撞就结束）、笔试（驾考题）。
5. **载具**：轿车、摩托、大货车「大运」（能撞车）、斜坡车；有第三人称、横竖屏、按键/方向盘两种操作、可调键位。
6. **MOD 工具箱**（看广告）：无敌、限速 9999、定速巡航、360° 旋转等——评论区最爽的部分。

## 四、玩家痛点（评论高频，按出现次数排序）

| 痛点 | 典型原话 |
|---|---|
| NPC 不打灯突然变道、无法预判 | 「连最起码的转向灯都不打，直接就转过来了」「能不能给我一个明显的提示」 |
| 一碰就死、不能撞开 | 「轻轻碰一下完好度直接变零」「就不能直接撞开吗」「狂暴模式就应该狂暴到底」 |
| 只有直路太单调 | 「加弯道」「加下坡」「隧道」「大桥」 |
| 操作：多点触控失灵、方向盘灵敏度低、按钮挡视野 | 「不能一边打方向一边踩油门」「方向打满了还避不开」「双闪那两个按键太挡视野」 |
| 红绿灯：没倒计时、红灯太长、停着被追尾 | 「加个红绿灯倒计时」「正常停红绿灯后面来的车直接追尾我」 |
| 想要记录、存档、排行 | 「撞多少车的记录表」「能不能搞个存档」 |
| 广告墙 | MOD / 无敌 / 大运都要看广告，次日失效 |
| 想要更多车型 | 跑车、摩托穿车缝、大巴 |
