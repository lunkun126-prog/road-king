# 公路之王 Plus

复刻 233 乐园《公路之王(驾考宝典)》并针对玩家吐槽重做的本地 H5 驾驶游戏。three.js 低多边形 3D，电脑/手机浏览器都能玩。
原作分析见 `docs/原作分析-公路之王驾考宝典.md`。

## 运行

```
双击 启动公路之王.bat          # 或：npm install && npm start
浏览器打开 http://localhost:8321
```

- 端口 **8321**（已登记 `D:\claude\launchpad\PORTS.md`）。
- 手机同一 WiFi 下玩：`set HOST=0.0.0.0 && node server.js`，手机打开 `http://电脑IP:8321`。
- 存档和排行榜在 `data/db.json`；服务没开时存档退回浏览器本地。

## 比原作好在哪（逐条对应评论区痛点）

| 原作的毛病 | 这里的做法 |
|---|---|
| NPC 不打灯突然别车，没法预判 | 所有 NPC 变道前**先打转向灯**（普通车 1.4 s，路怒族 0.8 s）；看灯读车是核心技巧 |
| 被别车只能认 | **喇叭**有用：打灯要挤进来的车会放弃；同车道慢车让行；路怒族可能报复急刹 |
| 轻轻一碰完好度归零 | 伤害按**相对速度**算，蹭一下掉几点，高速追尾才报废；撞得够狠会把对方撞飞 |
| 只有直路 | 程序生成的**弯道、坡道**，高速过弯会被甩向护栏；路口一律在平直段 |
| 红绿灯没倒计时、红灯 15 s、停车被追尾 | 顶部导航条有**距离 + 秒数倒计时**；红灯 10 s；后车用 IDM 跟车模型，守规矩停车不会被追尾（有单测保证） |
| 路口只是摆设 | 红灯时**横向真有车流**，闯红灯要自己躲 |
| 不能一边打方向一边踩油门 | 每个触控件独立跟踪手指，方向盘 + 油门可同时按；也支持键盘、手柄 |
| 方向盘灵敏度低、按钮挡视野 | 设置里可调灵敏度、方向盘/左右键两种操作；小按钮放仪表台，不压路面 |
| 想要记录撞了多少车、存档、排行 | 擦肩/创飞**连击计分**，本地存档，本地排行榜 |
| MOD、无敌、大运要看广告 | **没有广告**。金币开车赚，买车；MOD 工具箱（无敌/极速×3.6/空旷道路）设置里直接开，开了不上榜 |

## v2 新增（2026-09-25）

- **真实车模**：8 款致敬款（兰博 / 法拉利 / 阿尔法 / 保时捷 / 迈凯伦风格 + 家轿 + 两台仿赛摩托带骑手），NPC 车、公交、货车、行人（带走路动画）、行道树都换成免费 3D 模型，署名见 `CREDITS.md`。名字虚构，原贴图上的车标已抹掉。
- **提速**：超跑极速 305~355 km/h，仿赛 299。
- **三条路线**：城市主干道（车多、红绿灯、行人）/ 滨海高速（车少、无红绿灯）/ 盘山公路（几乎没车、急弯连坡）。
- **天气**：晴 / 雨 / 雪；雪地打滑、刹车距离接近翻倍。驾考新增「雨夜行车」「冰雪路面」两关（共 8 关）。
- **金币**：路上成排金币，一枚 5 金币；**右上角小地图**；**行人**（撞到会被撞飞，不出血；驾考直接挂科）。

## 三种模式

- **驾考模式**：6 关（起步 / 路口 / 施工变道 / 夜间 / 大雾 / 限时通勤），100 分起扣，90 分及格。闯红灯、撞车挂科；超速、不打灯变道、蹭护栏、撞锥桶、夜间不开大灯扣分。通关给星和金币，解锁下一关。
- **公路之王**：无尽车流。60 km/h 以上速度越快分越高；贴身超车叫「擦肩」，4 秒内连续擦肩叠连击到 ×10；路口横穿车流算「路口穿越」大分。越往后车越多、路怒族越多，每 6 公里一个昼夜循环。
- **大运狂飙**：开大运重卡 75 秒，撞谁谁飞，每创飞一辆 +1.5 秒。

车库：小轿车（默认）、摩托（窄车身钻缝、脆）、跑车（极速 285、擦肩加成）、大运重卡（撞飞一切、刹车长）。

## 操作

| | 键盘 | 手柄 | 触屏 |
|---|---|---|---|
| 油门 / 刹车 | W / S（↑ ↓，空格也刹） | RT / LT | 右侧踏板 |
| 转向 | A / D（← →） | 左摇杆 | 拖方向盘（或设置成左右键） |
| 转向灯 | Q / E | LB / RB | ◀ ▶ |
| 喇叭 / 大灯 / 视角 | H / L / C | X / — / Y | 📣 💡 🎥 |
| 暂停 / 静音 | Esc / M | Start | ❚❚ |

## 结构

```
server.js             零依赖 Node 服务：静态文件 + /api/profile + /api/leaderboard
public/js/road.js     道路生成（曲率积分、坡道、红绿灯周期）—— 纯逻辑
public/js/sim.js      玩家物理、NPC(IDM 跟车 + 打灯变道 + 路怒)、碰撞、计分、驾考规则 —— 纯逻辑
public/js/render.js   three.js 场景：按 100 m 分块生成路/楼/树/路灯/龙门架，车辆模型，相机，昼夜雾
public/js/input.js    键盘 / 手柄 / 多点触控
public/js/audio.js    WebAudio 合成音效（发动机、喇叭、撞击……无外部音频）
public/js/main.js     状态机、菜单演示、HUD、存档、结算
```
